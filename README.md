# LeiloesTDSat

## Descrição
O LeiloesTDSat é um sistema desenvolvido em Java que tem como objetivo
gerenciar leilões, permitindo o cadastro de itens/lotes para leilão, o
registro de participantes e o controle de lances realizados em cada leilão.

## Tecnologias utilizadas
- Java
- MySQL
- NetBeans (IDE / estrutura de projeto)

## Como executar
1. Importe o script do banco de dados (Script BD) disponível no Material
   Complementar para o seu SGBD (MySQL);
2. Configure as credenciais de conexão no arquivo de configuração do projeto;
3. Execute a aplicação pela IDE de sua preferência.
